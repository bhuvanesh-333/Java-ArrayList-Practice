# Java ArrayList Practice

This repository contains Java code exploring ArrayList fundamentals:
- Adding string and integer elements
- Iterating with enhanced for loops
- Using Iterator for traversal
- Basic display methods

## Features
- `linked` class: Manages string ArrayList with add operations and multiple iteration methods [web:10]
- `linkedlist` class: Handles integer ArrayList printing [web:8]
- Main method combines demonstrations with additional string list example
